Getting Started

Code Janitor is an intelligent coding assistant that helps you write, fix, and improve code. Here's what you need to know:

  • AI Provider: Select your AI provider from the dropdown (Ollama for local, or cloud providers like Groq, OpenRouter, Anthropic, NVIDIA)
  • Model Selection: Choose the AI model that best fits your needs (faster models for quick tasks, larger models for complex work)
  • Fast vs Heavy Mode: Fast mode for quick responses, Heavy mode for deeper analysis and better context understanding

Quick Action Buttons

Use these buttons for instant actions without typing:

Check syntax Scans your active file for syntax errors without using AI
Scan codebase Analyzes your entire workspace for syntax issues
Explain file AI explains what your active file does in plain English
Fix issues AI automatically detects and fixes syntax errors in your active file
Refactor AI improves code clarity, performance, and best practices
Generate tests AI creates unit tests for your active file
Add docs AI adds JSDoc/docstring comments to your code
Git status Shows your current Git status and changed files

Voice Input & Text-to-Speech

Use voice commands and hear AI responses:

  • Voice Input: Click the microphone button to speak your questions (requires microphone permission)
  • Text-to-Speech: Click the TTS button in header to enable AI response reading
  • Your spoken words appear in the input field in real-time
  • Works in Chrome, Edge, and Safari browsers
Pro Tip: Grant microphone permission once, and it will be remembered for future sessions

Web Search

Search the internet directly from Code Janitor:

  • Type your query in the search bar below the action buttons
  • Press Enter or click the Search button
  • Results appear in the chat with summaries and related links
  • No API key required - powered by DuckDuckGo

Chat with AI

Ask anything in natural language:

  • "Fix the syntax errors in this file" - AI will analyze and fix issues
  • "Explain what this function does" - Get clear explanations
  • "Add error handling to this code" - AI will improve your code
  • "Create a new component for user login" - Generate new files
  • "Run npm test" - Execute commands (with your approval)
Pro Tip: Use /fast or /heavy to switch modes, /scan to analyze your workspace, /ping to test AI connection, and /gstack to see the built-in Garry Tan inspired workflows.

Key Features

Agent Activity Panel

Track what Code Janitor is doing in real-time. Click "Show" to expand and see file operations, commands, and scans.

Connectivity Status

The green/red indicator in the header shows your internet connection status. Required for cloud AI providers and web search.

Safety Features

  • Code Janitor asks permission before running commands
  • File edits outside your workspace require approval
  • All changes are tracked and can be undone with Ctrl+Z
  • Syntax verification runs automatically after edits

Keyboard Shortcuts

Speed up your workflow with these shortcuts:

  • Alt + D: Format and fix code in active file
  • Ctrl + Alt + C: Open AI Chat Panel
  • Alt + P: Live Preview (HTML, React, Markdown, etc.)
  • Alt + L: Lint Code (ESLint)
  • Alt + V: Validate Frontend Dependencies
  • Ctrl + Alt + G: Visualize Codebase Graph (Graphify)

Setting Up API Keys

For cloud AI providers (Groq, OpenRouter, Anthropic, NVIDIA):

  • Select the provider from the dropdown
  • An API key input field will appear
  • Paste your API key and click "Save"
  • Click "Get key" link to obtain API keys from provider websites
  • Keys are stored securely in VS Code's secret storage
Free Options: Ollama (local, free), Groq (fast, free tier), OpenRouter (free models available)
