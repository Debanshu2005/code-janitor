## Problem Analysis

Code Janitor has THREE syntax validation checkpoints:

1. **Pre-edit diagnostics** ([`chat-panel.js:4340`](src/ai-agent/chat-panel.js:4340)): Checks existing file syntax before edits
2. **During-edit validation**: Should prevent bad code from being written
3. **Post-edit verification** ([`chat-panel.js:4417`](src/ai-agent/chat-panel.js:4417)): Checks files after edits and attempts auto-repair

### The Gap

- **PATCH actions** (old format): Had during-edit validation via [`_assessEditSafetyBeforeApply`](src/ai-agent/chat-panel.js:1565) ✅
- **APPLY_DIFF actions** (Bob-style): Had NO during-edit validation ❌

This meant `apply_diff` would write syntax-invalid code to disk, then post-edit verification would try to fix it - but the damage was already done.

## Solution Implemented

### 1. Enhanced [`apply-diff.js`](src/ai-agent/tools/apply-diff.js)

Added comprehensive syntax validation:

```javascript
// New functions added:
- getSyntaxCheckCommand() - Returns appropriate syntax checker for file type
- validateSyntax() - Validates content before writing using:
  * Python: python -m py_compile
  * JavaScript/TypeScript: node --check  
  * Java: javac
  * JSON: JSON.parse()
```

**Key fix**: Integrated into [`applyDiff()`](src/ai-agent/tools/apply-diff.js:260) workflow:
```javascript
// Validate syntax before writing
const syntaxValidation = await validateSyntax(absolutePath, newContent);
if (!syntaxValidation.valid) {
  throw new Error(`Refusing to apply syntax-invalid update...`);
}
```

**Windows compatibility**: Fixed path quoting (double quotes instead of single quotes)

### 2. Comprehensive Tests

Added tests in [`apply-diff.test.js`](src/ai-agent/tools/__tests__/apply-diff.test.js):
- Rejects invalid Python (IndentationError) ✅
- Rejects invalid JavaScript (SyntaxError) ✅
- Rejects invalid JSON ✅
- Accepts valid syntax changes ✅

All tests passing with manual verification completed.

## Validation Flow Now Complete

```
Pre-edit → During-edit (NEW!) → Post-edit
   ↓            ↓                  ↓
Check old   Validate new      Verify & auto-repair
  file      BEFORE write       if needed
```

**Result**: Syntax-invalid code is now blocked at the during-edit stage, preventing the error message you encountered: `"Refusing to apply syntax-invalid update to ai_module.py: IndentationError: unexpected indent (line 72)"`

The fix ensures both PATCH and APPLY_DIFF actions validate syntax before writing to disk.
